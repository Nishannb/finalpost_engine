# Kinmel AI video editing engine

```bash
cd ai-video-engine
npm install
npm run first-video -- "/path/to/your-talking-head.mp4"
npm run first-video -- "/path/to/your-talking-head.mp4" auto --north-star
npm run dev                  # API on :8090 for the mobile app
```
