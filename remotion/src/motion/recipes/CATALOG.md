# Motion recipe catalog (internal)

**Internal vernacular, not Jitter assets.** These recipes are our own reimplementation of the *feel* of common video motion-design moves (elastic type, smear, mask reveals, glitch ...) with Remotion springs, interpolation and CSS filters. No Jitter file, template or asset is used. For QA and Director docs: pick a recipe by beat intent, check the feel, check which host binds it by default.

The machine-readable twin is `catalog.json`; both mirror `MOTION_RECIPES` in `motionRecipes.ts` (a test fails if a recipe id is missing from either, or if `catalog.json` drifts from the registry).

Rules every recipe keeps: motion only (no browser / tab / notification chrome), already moving on frame 0, identity end state (WP19: `orbit_drift` is the one CONTINUOUS recipe: it enters, then drifts a few px over the whole hold), duration-adaptive (entrance 8-24 frames, at most 40 % of the graphic). A generated graphic is also machine-checked for these (`server/src/lib/motionAestheticGate.ts`).

**Driver**: `transform` recipes wrap any layer (and can drive each unit of `KineticText` via `recipeId`); `glyph` recipes need `text`; `number` recipes need `value`.

**Intent -> default recipe**: hook = elastic_type_snap, punchline = stretch_squash_pop, evidence = split_mask_reveal, list = type_trail, stat = counter_snap, pivot = smear_blur_in, payoff = split_mask_reveal. The other recipes of an intent are its variety pool (`recipesForIntent`).

**Exits + SFX (WP14F).** `<MotionRecipe exit>` runs a vernacular exit matched to the entrance family: type_physics smear/spin/glitch → `smear_blur_out`; reveal_mask / image_story → `close_mask`; else `scale_blur_out`. Soft fade alone is not the exit. Suggested SFX peaks (`recipeSfxPeaks`): elastic / stretch / gooey → `pop` near settle; smear / glitch / spin / trail / scramble → `whoosh` on start; split / pixel / nested → `whoosh` mid-open; counter → `hit` on snap. Polish explain schedules those peaks when the graphic carries `recipeId`.

**Image family (WP19).** `logo_slam`, `sticker_pop`, `still_push_in`, `card_tilt_in`, `orbit_drift` are the image_story objects (logos, stickers, stills, screenshot cards). Their first intent is `media`, so they never change the default or the first variants of an existing intent; they sit at the end of the evidence / payoff / punchline / hook pools. SFX: logo_slam = hit, sticker_pop = pop, still_push_in / card_tilt_in = whoosh, orbit_drift = soft whoosh at start.
